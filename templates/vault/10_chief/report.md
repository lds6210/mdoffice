# Chief of Staff — running report

The Chief writes the running summary here. The CEO reads this file (and nothing else) for status.

Format the Chief should follow:

```
## <timestamp> — <one-line directive recap>

Status: <one of: planning | delegating | in-progress | blocked | complete>
Team: <list of active specialists>

### Highlights
- <newest deliverable, one line, with link to specialist's output file>
- <...>

### Risks / blockers
- <one line each, or "none">
```

(empty until the office starts)
