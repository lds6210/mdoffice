# Directives from the CEO

This is the only file you (the CEO) need to write to.
Anything you put below the marker is treated as a fresh directive.
The Chief polls this file and reacts to changes.

Tips:
- Be terse. One paragraph is plenty.
- If you want a specific team size, say "use 2 specialists" etc.
- If you want a specific role excluded, say "no QA needed".
- To cancel, replace the directive with the word "STAND DOWN".
