# Assets — the company's growing IP

This folder accumulates durable artifacts that outlive their originating task. The Chief promotes specialist output into here when something proves reusable.

Subfolders:
- `code/`      — reusable snippets, modules, scaffolds
- `design/`    — design docs, ADRs, decision records
- `docs/`      — writeups, research notes, references
- `playbooks/` — repeatable processes (deploy checklist, incident response, etc.)

The CEO doesn't normally read these directly — the Chief surfaces them in `10_chief/report.md` when relevant. But everything is plain markdown, so you can grep and link freely.
